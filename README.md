# 📦 Inventory Management System

A web-based **Inventory Management System** built using **HTML, CSS, and JavaScript** to manage products, track stock, and record sales.

## 🚀 Features

* 📊 Dashboard with product and sales statistics
* ➕ Add products
* ✏️ Edit and update products
* 🗑️ Delete products with confirmation
* 🔍 Search products by name or category
* 📦 Track available stock
* ⚠️ Low Stock and Out of Stock status
* 💰 Sales Management
* 🛒 Sell products and automatically reduce stock
* 📋 Sales History
* 🕒 Sale date and time tracking
* 💾 LocalStorage data persistence
* 🛡️ Input validation
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Browser LocalStorage

## ⚙️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/jaswanthogu802-ops/inventory-management-system.git
```

2. Open the project folder.

3. Open `inventory.html` in your browser.

You can also use **VS Code Live Server** to run the project.

## 💡 Project Workflow

```text

     ↓

     ↓

Sales Recorded

Dashboard Updated
```
